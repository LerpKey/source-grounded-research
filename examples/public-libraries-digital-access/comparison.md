# Baseline comparison: without vs. with Source-Grounded Research

This comparison uses the same prompt and topic. The baseline is intentionally illustrative; the enhanced report demonstrates the target workflow rather than claiming a controlled scientific experiment.

| Dimension | Without the skill | With the skill |
|---|---|---|
| Scope | Broad and implicit | Defines the question, audience, scope, date, and terms |
| Source quality | No sources shown | Uses institutional primary/authoritative sources |
| Traceability | Claims cannot be checked claim by claim | Material claims have nearby links to named sources |
| Fact/inference separation | Recommendations and factual claims blend together | Verified facts, inferences, and recommendations are labeled |
| Precision | “Libraries solve the digital divide” is an overbroad conclusion | Libraries are described as one access-and-support layer |
| Measurement | Suggests investment priorities without an evaluation model | Separates availability, use, capability, and outcomes |
| Uncertainty | No limitations | States what the sources do not establish |
| Reproducibility | No source window or method | Records an as-of date, method, and source ledger |

The important change is not simply adding citations. The skill changes the unit of work from “write a convincing paragraph” to “make a bounded claim that a reader can inspect.”
