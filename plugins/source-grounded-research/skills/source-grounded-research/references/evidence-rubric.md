# Evidence Rubric

Use this rubric both while researching and when evaluating a finished report.

## Claim types

| Type | Meaning | Citation expectation |
|---|---|---|
| Verified fact | Directly supported by an inspected source | Inline citation required |
| Synthesis | A faithful combination of multiple supported facts | Cite all material inputs |
| Inference | A reasoned interpretation not stated directly by a source | Cite inputs and label as inference |
| Viewpoint | A recommendation, value judgment, or preference | Identify the author or decision owner |
| Unknown | The available evidence does not establish the claim | State the gap and what would resolve it |

## Evidence quality

Score each material claim from 0 to 3:

- `3` — direct, authoritative, current, scope-matched support;
- `2` — credible support with a minor scope, date, or methodology limitation;
- `1` — indirect, weak, secondary, or incomplete support;
- `0` — unsupported, contradicted, or incorrectly cited.

Do not hide a score of 0 or 1. Either narrow the claim, add stronger evidence, or mark it unresolved.

## Report-level evaluation

Score each dimension from 0 to 4:

| Dimension | 4-point standard |
|---|---|
| Source quality | Primary and authoritative sources are used where available |
| Traceability | Readers can move from every material claim to the exact source |
| Citation correctness | Links and cited passages actually support the wording |
| Coverage | The report answers the requested questions without material evidence gaps |
| Fact/inference separation | Inferences and recommendations are explicitly labeled |
| Uncertainty handling | Conflicts, limitations, and unknowns are visible |
| Link health | Links are complete, accessible, and not misleading |
| Usefulness | The report is concise, decision-relevant, and readable |

An auditable report should not pass by average score alone. Require no critical dimension below 3, and no high-impact claim with evidence below 2 unless it is explicitly presented as unresolved.
