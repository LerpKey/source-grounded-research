# Benchmark prompts

## Public libraries and digital access

Research the role of public libraries in digital access and inclusion. Write a concise report for a public-interest technology team. Use sources available as of 2026-08-18, prioritize primary and institutional sources, distinguish verified facts from inferences, cite material claims inline, and explain important limitations. Use Markdown.

Run this prompt twice:

1. in a fresh context without `source-grounded-research`;
2. in a fresh context with `source-grounded-research` loaded.

Keep the source window, output format, and time budget the same. Save the raw outputs before scoring them.
