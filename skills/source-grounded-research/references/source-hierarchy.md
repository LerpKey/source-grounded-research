# Source Hierarchy and Search Strategy

Use the strongest source that directly answers the claim. “Primary” does not mean “always correct”; inspect methodology, scope, incentives, and update status.

## Default source ladder

1. Original law, regulation, standard, filing, dataset, experiment, survey instrument, or first-party documentation.
2. Official statistics, institutional reports, technical papers, or peer-reviewed research.
3. Reputable journalism that links to or quotes primary evidence.
4. Expert analysis, trade publications, think-tank reports, and professional commentary.
5. Aggregators, encyclopedias, search snippets, social posts, and unattributed summaries.

Use lower-level sources for discovery, context, or triangulation. Do not use them as the sole support for high-impact claims when a primary source is available.

## Adapt the hierarchy to the topic

- **Policy and regulation:** statute or regulation → agency guidance → implementation records → reputable analysis.
- **Markets and companies:** filing or audited report → company disclosure → regulator or dataset → specialist reporting.
- **Science and medicine:** original study → systematic review or consensus guidance → institutional summary → journalism.
- **Products and technology:** vendor documentation or release notes → reproducible test or benchmark → independent review.
- **Public-interest questions:** official statistics and original surveys → methodology-aware research → reputable reporting → commentary.

## Search sequence

1. Search broadly to discover terminology and candidate sources.
2. Search by the exact document, dataset, institution, product, or study name.
3. Search within authoritative domains and repositories.
4. Trace important claims to the original source.
5. Search for disconfirming evidence, competing definitions, and known limitations.

Do not stop after finding a source that agrees with the expected answer. Search for the strongest plausible counterargument and document whether it changes the conclusion.

## Source record

Record this minimum metadata for every source used in a material claim:

| Field | Requirement |
|---|---|
| ID | Stable local ID such as `S1` |
| Title | Exact page or document title |
| Publisher | Organization, author, or journal |
| Date | Publication or last-update date, if available |
| URL | Complete canonical URL |
| Accessed | Date inspected |
| Evidence | Passage, table, figure, or data field used |
| Limits | Scope, method, uncertainty, or conflict of interest |
